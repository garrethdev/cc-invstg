# CC Invstg

Working folder for *Confessions: The Secret Past, Present, and Future of Money*: research notes and the investigation tools.

- `CLAUDE.md`: project brief (concept, format, look, people, fact-check flags).
- `project-map.md`: the four areas (visuals, stories, tech, rollout).
- `tools-scratchpad.md`: the tooling plan and services on hand.
- `graph/`: Connection Mapper (document extractor, SQLite graph, queries, interactive map).
- `source-locator/`: source footprint audit / identification pipeline; read `BLUEPRINT.md` first.
- `papers/`: reference papers and notes.

Investigation data (`graph/graph.db`, review files, rendered maps, collected posts) is ignored by git on purpose. API keys live in the macOS Keychain, never in files.
